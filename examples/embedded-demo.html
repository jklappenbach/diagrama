diagrama — everything it can do

Six diagram types from KDL. Wheel / Ctrl+↑↓ to zoom, drag the background to pan.

system — shapes · icons · edges

family shapes (compute rect, storage cylinder, messaging parallelogram, network pill), group kinds (boundary/cluster/zone borders), and edge decoration (owns ◆, refs dashed, cardinality, glyph).

gantt (calendar) — schedule · colors · dependency bands

hours granularity, auto-derived swimlanes, complementary palette (parent/child contrast), and a narrow vertical band per dependency (its parent's color). Critical path = bold border.

class — UML compartments

3-compartment boxes (name/«stereotype», attributes, methods); inheritance/implementation edges.

state — state machine

initial/final/choice pseudo-states, rounded states, transitions with trigger [guard] / action.

sequence — temporal

participants + lifelines, messages in document order (sync/async/return/self), an alt fragment with branches.

pipeline (CI/CD)

steps shaped by role (trigger/source/build/test/approval/deploy), stages as groups, outcome-routed edges (flow/onsuccess/manual), tool icons via packs.
