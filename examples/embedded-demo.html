diagrama — everything it can do

Six diagram types + gantt schedule/organize/list/detail views, from KDL. Ctrl+wheel / Ctrl+↑↓ to zoom, drag the background to pan (plain wheel scrolls).

system — shapes · icons · edges

family shapes (compute rect, storage cylinder, messaging parallelogram, network pill), group kinds (boundary/cluster/zone borders), edge decoration (owns ◆, refs dashed, cardinality, glyph).

system — shape gallery (every family & subtype)

compute = rectangle, storage = cylinder, messaging = parallelogram, network = pill. Vendor packs resolve vendor:service to the right base shape (badge top-left; real vendor SVG logos are the next step).

gantt — calendar view

hours granularity, auto-derived swimlanes, complementary palette (parent/child contrast), a narrow color band per dependency. Critical path = bold border.

gantt — organize view (mode="timeless")

same tasks as a dependency graph: nodes gravitate by depth (deps to the left), arrows point each task → its dependency.

gantt — task list view

the schedule as a table (start/end computed; critical marked).

gantt — task detail view

one task's full detail (dependencies, what it blocks, ticket, notes).

class — the full UML primitive set

all node kinds (class / «interface» / «enum» / abstract) and all relationship kinds (inheritance, implementation, association, aggregation, composition, dependency) with multiplicity.

state — state machine

initial/final/choice pseudo-states, rounded states, transitions with trigger [guard] / action.

sequence — temporal

participants + lifelines, messages in document order (sync/async/return/self), an alt fragment with branches.

pipeline (CI/CD)

steps shaped by role (trigger/source/build/test/approval/deploy), stages as groups, outcome-routed edges (flow/onsuccess/manual).
